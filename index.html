Nordic Retail Group

A responsive webshop built with React, TypeScript, Vite, and React Router 7. The original assignment was intended for Next.js, but I chose a separate React frontend and ASP.NET Core backend.

The backend is a .NET CRUD API deployed independently on Render. It connects to a PostgreSQL database hosted on Supabase.

The frontend uses a vertical-slice architecture.

Authentication is handled by Supabase Auth, with preconfigured customer and admin accounts.

The webshop includes product search and filtering, pagination, product details, a persistent shopping cart, and admin product management.

Wiki Voyage

A React and TypeScript application for exploring entities and their relationships using data from Wikipedia, Wikidata, and Wikimedia Commons.

The application demonstrates modern frontend development with React, TypeScript, Vite, and Tailwind CSS, with a component-based architecture and strongly typed data models.

Wikidata data is retrieved dynamically using SPARQL, while Wikipedia and Wikimedia Commons provide additional content and images.

The application includes multiple entity types, reusable information components, navigation paths, source tabs, image galleries, and a customizable theme system.

Game of life

An implementation of Conway’s Game of Life built with a WPF frontend.

The project is designed with Clean Architecture in mind, ensuring a clear separation between domain logic, application flow, and presentation.

The domain layer is modeled using domain-driven design principles, including entities, value objects, and aggregates, where the business logic is encapsulated within the domain itself.

The focus of the project is maintainability, testability, and demonstrating how classic problems can be structured using modern architectural patterns.

Pacman

A recreation of the classic Pac-Man game implemented with a layered architecture consisting of Domain, Application (orchestration), and a WPF frontend.

The project follows SOLID principles and emphasizes keeping domain objects responsible for their own logic and validation.

It uses domain-driven design concepts such as entities, value objects, and aggregates to model game behavior.

The architecture is designed for clarity and extensibility, with future improvements planned such as implementing ghost AI using A* pathfinding.
